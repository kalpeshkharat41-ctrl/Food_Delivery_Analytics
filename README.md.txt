# 🛵 Food Delivery Analytics & Query Optimization (SQL)

A comprehensive SQL data analysis project exploring customer purchasing behavior, order fulfillment metrics, operational efficiency, and revenue trends across different city tiers for a food delivery platform.

---

## 📌 Executive Summary

This project analyzes transactional data from a food delivery platform using PostgreSQL. The primary focus is evaluating business-critical KPIs such as cancellation rates, delivery efficiency, peak demand hours, and customer spending segments through structured SQL queries.

### 🎯 Key Insights Addressed:
- **City Tier Benchmarking:** Identifying high-revenue regions vs. areas prone to delivery delays and cancellations.
- **Operational Metrics:** Assessing how delivery delays directly impact overall customer ratings.
- **Customer Segmentation:** Classifying users by spending tiers (`Low Spender`, `Medium Spender`, `High Spender`) and comparing premium vs. non-premium spending patterns.
- **Advanced Trend Analysis:** Measuring Month-over-Month (MoM) revenue growth using SQL Window Functions.
